## Descripción

### Escenario

Una tienda de productos tecnológicos necesita controlar su inventario con un programa desarrollado en lenguaje ensamblador MIPS.

Al iniciar la jornada, el sistema registra 12 unidades de un producto y 25 unidades de otro registro de inventario. El programa realiza operaciones aritméticas, como sumas y restas, para calcular cantidades y diferencias. Durante la ejecución, algunos registros se consultan varias veces y otros se sobrescriben con nuevos valores.

Finalmente, el sistema compara un resultado calculado con cero. Si es diferente de cero, almacena el código 101, que indica que el inventario fue procesado correctamente. En caso contrario, almacena 0. El estado final se guarda en una posición de memoria.
